\subsection{Páginas de progreso y marcas personales}
Se implementaron dos páginas en HTML, CSS y JavaScript, servidas por Express desde el mismo origen que la API. Se eligieron módulos compartidos para la sesión, las solicitudes y los estilos; así se conserva una navegación consistente sin incorporar un framework adicional. Las páginas consultan el perfil autenticado y los endpoints personales; no incluyen resultados simulados en el código de la interfaz.

La página de progreso consulta la racha y los totales por categoría del servidor, y distribuye las asistencias por semana para presentar su gráfico. También muestra las asistencias recientes y las próximas reservas. La página de marcas permite crear, consultar, modificar y eliminar registros, además de buscar, filtrar y ordenar el historial. Su gráfico reúne únicamente registros del mismo ejercicio, tipo y unidad para evitar comparaciones incompatibles.

Cada operación muestra carga, error o confirmación según la respuesta de la API. Las listas sin registros tienen un estado vacío. Los formularios conservan sus datos ante un rechazo y las eliminaciones solicitan confirmación. Al terminar la sesión se retiran los datos de la pantalla. La comprobación de permisos se mantiene en el servidor.

El archivo de Figma no permitió su lectura con la cuenta conectada. Por ello se preparó una propuesta visual con jerarquía tipográfica, contraste y distribución adaptable, pendiente de contrastar con el prototipo. No se declara fidelidad visual verificada. La revisión de navegador se realizó sobre una cuenta y una base sintéticas; la compatibilidad con un dispositivo móvil físico y la integración con las demás pantallas siguen pendientes.
